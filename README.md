# Handwritten Character Recognition

## Overview
This project is a CNN-based handwritten digit recognition system developed using TensorFlow and the MNIST dataset.

## Features
- Handwritten digit recognition
- CNN model
- 98.83% Test Accuracy
- Model saved as .keras file

## Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib

## Dataset
MNIST Dataset

## How to Run

1. Install dependencies
pip install -r requirements.txt

2. Train Model
python train_model.py

3. Test Model
python test_model.py

## Output

Predicted Digit: 7
Actual Digit: 7
